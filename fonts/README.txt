Custom fonts for the WindowSniper HUD
===============================

Drop font files you have the rights to use into this folder, named:

  hud.ttf / hud.otf / hud.woff2        -> cash, ammo and the rest of the HUD
  banner.ttf / banner.otf / banner.woff2 -> the big "KILLED" banner

Then restart WindowSniper (menu bar icon -> Quit WindowSniper, then run `windowsniper`).
If a file isn't here, WindowSniper uses its built-in font.
